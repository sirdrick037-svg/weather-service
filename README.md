# Simple Weather Service

A simple Python weather service that generates simulated weather data for predefined cities.

## Features

- Generates random weather data
- Supports multiple predefined cities
- Provides temperature, humidity, and weather condition
- Converts weather data to JSON
- Converts weather data to XML
- Supports filtering by city
- Handles invalid cities
- Includes an XML Schema (XSD)
- Includes unit tests

## Predefined Cities

- Nairobi
- London
- New York
- Tokyo
- Sydney

## Weather Data

Each city has:

- City name
- Temperature
- Humidity
- Weather condition

## Running the Program

Run:

```bash
python weather_service.py
